# Rust, rebuilt from scratch

The suite is rebuilt in Rust instead of extending the Go code. The Go version suited server-rendered CRUD, but the suite is three to five times larger and two things now favour Rust: Typst is a Rust library, so documents compile in-process with file, font and package access under the app's control, which uploaded layouts need (ADR 0012); and a ledger's invariants (balanced postings, nothing changes once locked, money never a float) are cheaper to enforce with enums, newtypes and exhaustive matches. The cost is roughly 20–30 % more effort and slower builds. The Go version stays in use until the Rust version replaces it; its data is not migrated.
